// WHAT IT DOES

PY HUNTER scans every corner of your machine — PATH, Homebrew, pyenv, conda, python.org framework installs, and every virtual environment in your home directory — then tells you which versions are compliant and which ones need to go.

// FEATURES

🔍 FULL SYSTEM SCAN Finds Pythons in PATH, Homebrew, pyenv, conda/mamba, python.org framework installs, and nested virtual environments.
📊 COMPLIANCE AUDIT Colour-coded status table. EOL in red, security-only in yellow, fully supported in green.
⚡ AUTO VENV UPGRADE Recreates virtual environments with a newer Python, preserving all installed packages automatically.
🤖 FULL AUTO MODE One flag fixes everything: upgrades Homebrew Python, repairs broken venvs, upgrades all venvs, verifies PATH shadowing and shell config.
🩹 BROKEN VENV REPAIR Detects venvs whose source Python was silently deleted (e.g. after a brew upgrade) and rebuilds them.
🕹️ INTERACTIVE MODE Step through each problem installation and decide: upgrade, delete, suggest, or skip.
🌈 RETRO UI Classic 80s BBS terminal aesthetic. Neon green, scan lines, animated progress bars.
🛡️ DRY RUN MODE Preview every action before it happens. No surprises.

// QUICK START

$ pip install git+https://github.com/mikebignell/python-version-hunter.git

$ pyhunter                          # scan and report

$ pyhunter --interactive           # decide for each issue

$ pyhunter --upgrade-venvs         # auto-upgrade all EOL venvs

$ pyhunter --full-auto             # fix everything in one shot

$ pyhunter --full-auto --dry-run   # preview only

// FULL AUTO MODE

Run pyhunter --full-auto to remediate your entire Python environment in one command:

$ pyhunter --full-auto          # interactive confirmation
$ pyhunter --full-auto --yes     # skip confirmation
$ pyhunter --full-auto --dry-run # preview only
  • Step 1 — Homebrew upgrade: runs brew upgrade python for all installed Python formulae
  • Step 2 — pyenv install: installs the latest stable Python via pyenv and sets it as global default (if pyenv is present)
  • Step 3 — Broken venv scan: finds venvs whose source Python has been deleted from disk — this happens silently after every brew upgrade or macOS update
  • Step 4 — Broken venv repair: recreates each broken venv with the new Python, restoring all packages
  • Step 5 — Upgrade out-of-date venvs: recreates every venv on an old cycle or patch, then upgrades pip inside each one
  • Step 6 — PATH shadowing check: verifies which python3 resolves to Homebrew, not /usr/bin/python3
  • Step 7 — Shell config check: warns if brew shellenv is missing from ~/.zshrc / ~/.bash_profile; also scans for .python-version files pinning EOL versions

// HOW VENV UPGRADE WORKS

  • Reads pip freeze output from the existing venv
  • Backs up requirements to <venv_name>_requirements_backup.txt
  • Deletes the old venv directory
  • Creates a new venv with the target Python
  • Reinstalls all packages + upgrades pip

⚠ Package compatibility is not guaranteed across Python versions. Review the backup file if reinstall has issues.
